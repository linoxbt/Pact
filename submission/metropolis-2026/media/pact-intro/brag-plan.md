# Brag plan: Pact official introduction

## What is this app?
Pact lets a developer connect an agent, define its authority, check requests before execution and inspect the outcome.

## Angle and hook
“Agents can act. Who sets the limits?” opens the film. The answer is shown through the real Connect documentation, a gateway decision graphic, and the public Explorer. This is a product introduction, not a claim that every HTTP event is anchored onchain.

## Format and tone
Polished, landscape 1280 × 720, 24 seconds. Pact forest `#203d32`, mint `#b9e7c6`, warm paper `#f7f7f2`, bold clean type. Concise copy and continuous motion.

## User flow
Connect an agent → choose endpoint, grant and policy → Pact checks the request → inspect an outcome. The first and last product captures are from Pact's public documentation and Explorer; the central gateway sequence is an explanatory graphic.

## Storyboard

| Time | Scene | On-screen message | Motion |
|---|---|---|---|
| 0–6s | Authority question | “Agents can act. Who sets the limits?” | Orbit, wordmark and question enter; settled hold. |
| 6–12s | Connect | Endpoint → Grant → Policy | Real Docs capture moves into view; pointer and steps advance. |
| 12–18s | Gateway | “One request. One clear decision.” | Agent → Pact → Upstream rail; allowed and denied labels resolve. |
| 18–24s | Outcome | “From decision to outcome.” | Real Explorer capture, receipt qualification and Pact URL. |

## Audio
Warm low-volume Brag music, two restrained CC0 interface cues at interaction and decision moments, fade out with the wordmark. No narration: the copy is designed to read silently on X.
