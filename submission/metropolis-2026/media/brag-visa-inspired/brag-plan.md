# Brag plan: Pact brand film

## What is Pact?
Pact is an enforceable authority and economic accountability layer for autonomous agents across APIs and Monad testnet.

## Angle and hook
Use the reference film's editorial structure—quiet question, bold brand reveal, giant kinetic verbs, modular system grid, fast application montage, calm closing—but make every word, color, visual and product claim Pact's own. Opening: “An agent can act. Who authorized it?”

## Key product moments
- Developer registers an agent and endpoint; grants and ordered policies set its limits.
- Pact's gateway allows a permitted call, denies a forbidden method before forwarding and logs the decision.
- Monad testnet receipt 1 is inspected in the public Explorer; it is historical, checkable test evidence.

## Tone / format
Polished editorial brand film with an application walkthrough in the center. 1280×720 landscape, 180 seconds. Ten moving Brag chapters: 16 + 18 + 18 + 18 + 18 + 18 + 18 + 18 + 20 + 18. Narration is synthesized locally with Hyperframes/Kokoro. Visible pointer/tap cues are synchronized with touch sounds.

## Brand identity
Cream `#F7F7F2`, forest `#203D32`, mint `#B9E7C6`, black `#111A15`; sans-serif display. A pair of green/mint bars represents grant plus policy. Curved lines carry a proposed request to the decision point.

## Storyboard
1. **Question, 0–16s:** white space, small question becomes big; a thin Pact boundary draws through it. SFX: soft reveal.
2. **Pact reveal, 16–34s:** forest card, green/mint bars, team/workspace photo masks, real landing screen. SFX: one warm impact and two bars.
3. **Connect, 34–52s:** oversized cropped letters resolve to CONNECT; real docs screenshot and sequential agent → endpoint → grant → policy → key. Visible touch marker on docs navigation. SFX: 3 light taps.
4. **Enforce, 52–70s:** clear original policy-flow diagram. Allowed GET reaches upstream; denied DELETE stops at the Pact boundary. Label as an explanatory flow, not a captured live request. SFX: clean allow chime and muted denial.
5. **See, 70–88s:** typography-grid of Agents, Endpoints, Policies, API keys, Approvals, Activity; copy stresses matched rule and reason. Actual Pact documentation/product screenshots appear in the grid. SFX: restrained card placements.
6. **Verify, 88–106s:** pace accelerates. Real public Explorer screenshots: enter receipt ID 1, inspect, scroll to `verification.valid: true`. Historical testnet label. Touch clicks are audible exactly at click moments.
7. **Owner, 106–124s:** moving photographic composition links the human owner to grant, agent, and policy.
8. **Build, 124–142s:** a camera move through real public documentation, with a cursor and sequential developer steps.
9. **System, 142–162s:** moving editorial strips and photographic/UI composites connect agent, grant, policy, approval, and receipt.
10. **End, 162–180s:** fast brand-application mosaic from Pact photos/UI, then quiet white closing: “Authority with an outcome.” Pact logo and product URL. Music fades.

## Audio
Use one Brag bundled professional music bed under the narration. Voice is clear and center-mixed. A low-HF click accompanies real/simulated visible taps; soft impacts mark large type landings. No reuse of the reference soundtrack. Avoid dense SFX during speech.

## Truth boundaries
The October 8 agent run was real but is historical; its actor and grants expired/revoked. HTTP activity is private and not anchored. The public receipt root can be checked against Monad testnet but does not prove real-world delivery.
