# Pact Brag film plan

## Angle
A developer can let an agent act through a narrow, explainable boundary. Pact carries that story from protected HTTP access to a checkable Monad testnet economic receipt.

## Hook
“An agent can call an API. Who authorized it?” The first chapter opens on the real Pact product.

## Storyboard
Ten 18-second chapters: problem; product; connect agent; gateway allow; gateway deny; activity; Monad grant; funded milestone; public receipt interaction; try Pact. `build-video.mjs` contains final caption copy, and `DEMO_VIDEO.md` carries the optional human narration script.

## Visuals
Use the public landing page, docs and Explorer captured from the deployed site. Chapter nine uses an actual browser interaction: enter receipt ID 1, click Inspect record, show `verification.valid: true`. Other frames are branded explanatory cards, not fake Console states.

## Audio
Use one low-volume Brag bundled music bed, with entrance and ending fades. The user did not request synthesized narration. The optional spoken script is supplied separately.

## Proof boundary
The October 8 test was real but historical. Its actor task expired and grants were revoked. No new private Console run is represented. HTTP activity is not described as chain-anchored. The receipt claim is limited to a checkable root on Monad testnet.

## Outro
Try the public product, read the SDK/MCP documentation, and inspect the public receipt and source.
